# Мій словник

Застосунок для вивчення англійських слів на телефоні: картки, режим «Написати» і режим «Вибір», інтервальне повторення.

- Відкрий сайт цього репозиторію (GitHub Pages) у Safari на iPhone.
- Натисни «Поділитися» → «На початковий екран» / «На экран Домой».
- Прогрес зберігається тільки на телефоні. Резервну копію можна зробити кнопкою «Скопіювати код» у самому застосунку.
